# Food Lover - Interactive Restaurant Website

A premium, fully responsive, and highly interactive restaurant website built from scratch using pure web technologies. This project showcases advanced layout design and dynamic user interactions without relying on any external libraries or frameworks.

## 🚀 Live Demo
[Click here to view the live website](https://basmala-taima.github.io/Food_lovers/)

## ✨ Features
* **Dynamic Content Rendering:** Menu items and food data are generated dynamically from JavaScript arrays/objects into the DOM, showing proficiency in handling data-driven UIs instead of hardcoded HTML.
* **Interactive Food Gallery:** Implemented a custom image modal/lightbox effect where clicking on a dish smoothly enlarges it for a detailed view.
* **Automated Offers Slider:** A custom-built auto-playing carousel/slider for special offers that rotates automatically using time-based JavaScript logic.
* **Robust Form Validation:** Built client-side input validation for the contact/reservation form to ensure data integrity and improve user experience.
* **Pure CSS Styling:** Advanced layout structure using CSS Flexbox, Grid, custom backgrounds, and smooth transitions for a pixel-perfect design.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure.
* **CSS3 (Pure):** For advanced layout architecture, typography, and animations.
* **JavaScript (Vanilla ES6+):** For the entire application logic, dynamic rendering, sliders, and form validation.
